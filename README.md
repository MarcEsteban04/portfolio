# portfolio

Marc Esteban's portfolio website.

## Tech stack

- [Next.js](https://nextjs.org) (App Router, TypeScript, `src/` directory)
- [Tailwind CSS](https://tailwindcss.com) v4 (via `@tailwindcss/postcss`)
- ESLint (`eslint-config-next`)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Pages live in `src/app/`; global styles and the Tailwind import are in `src/app/globals.css`.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |
